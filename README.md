# Meena Bazaar 3F

یہ ایک mobile-first PWA prototype ہے۔ Browser میں کھولیں، پھر Android Chrome میں **Add to Home Screen / Install** کیا جا سکتا ہے۔

## Production version
حقیقی marketplace کے لیے backend/database، user accounts، image storage، chat، phone/WhatsApp actions، moderation، payment gateway، featured ads، notifications اور admin dashboard شامل کرنا ہوگا۔

Android native package کے لیے Capacitor استعمال کیا جا سکتا ہے؛ Capacitor web app کو Android/iOS native runtime میں لے جا سکتا ہے، مگر APK/AAB build کے لیے Android Studio/Android SDK درکار ہے۔
